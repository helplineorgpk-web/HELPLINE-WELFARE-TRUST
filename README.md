## Prerequisites

Before you begin, ensure you have met the following requirements:

- **Node.js**: Version **16.20.0** is preferred.
- **npm**: Comes bundled with Node.js.

> **_Note:_** It's recommended to use [nvm (Node Version Manager)](https://github.com/nvm-sh/nvm) to manage multiple Node.js versions on your machine.

## Installation

Follow these steps to set up the project locally:

1. **Clone the Repository**

   ```bash
   git clone https://github.com/yourusername/lifeline.git

2. **Install Dependencies**

    nvm install 16.20.0
    nvm use 16.20.0

    **Install with Legacy Peer Dependencies**
        npm install --legacy-peer-deps

## Running the Server

    npm run dev

## Building for Production

    npm run build
